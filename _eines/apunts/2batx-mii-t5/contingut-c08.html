⟪Límits que depenen d'un paràmetre‖Límites que dependen de un parámetro‖Limits depending on a parameter⟫

⟪Mètode‖Método‖Method⟫
  1. ⟪Calculem el límit com si el paràmetre fóra un nombre, amb les tècniques dels apartats anteriors. El resultat serà una expressió amb el paràmetre.‖Calculamos el límite como si el parámetro fuera un número, con las técnicas de los apartados anteriores. El resultado será una expresión con el parámetro.‖Compute the limit as if the parameter were a number, with the techniques of the previous sections. The result is an expression in the parameter.⟫
  2. ⟪Imposem la condició de l'enunciat (que valga un nombre donat, que siga finit…) i resolem l'equació.‖Imponemos la condición del enunciado (que valga un número dado, que sea finito…) y resolvemos la ecuación.‖Impose the condition in the statement (a given value, a finite limit…) and solve the equation.⟫
  3. ⟪Si el comportament canvia segons el valor del paràmetre, discutim els casos per separat.‖Si el comportamiento cambia según el valor del parámetro, discutimos los casos por separado.‖If the behaviour changes with the parameter, discuss each case separately.⟫

⟪Clau per a \(\displaystyle\lim_{x\to a}\frac{P(x)}{Q(x)}\) amb \(Q(a)=0\): perquè el límit siga finit, cal que també \(P(a)=0\) (si no, seria \(\frac{k}{0}=\infty\)).‖Clave para \(\displaystyle\lim_{x\to a}\frac{P(x)}{Q(x)}\) con \(Q(a)=0\): para que el límite sea finito, hace falta que también \(P(a)=0\) (si no, sería \(\frac{k}{0}=\infty\)).‖Key for \(\displaystyle\lim_{x\to a}\frac{P(x)}{Q(x)}\) with \(Q(a)=0\): for the limit to be finite, we also need \(P(a)=0\) (otherwise it would be \(\frac{k}{0}=\infty\)).⟫

✎ ⟪Exemples‖Ejemplos‖Examples⟫
  1. ⟪Troba \(a\) perquè‖Halla \(a\) para que‖Find \(a\) such that⟫ \(\displaystyle\lim_{x\to+\infty}\left(\sqrt{x^2+ax}-x\right)=3\).

    \(\displaystyle\lim_{x\to+\infty}\frac{x^2+ax-x^2}{\sqrt{x^2+ax}+x}=\lim_{x\to+\infty}\frac{ax}{2x}=\frac a2\)

    \(\dfrac a2=3\Rightarrow a=6\)

  2. ⟪Troba \(a\) perquè‖Halla \(a\) para que‖Find \(a\) such that⟫ \(\displaystyle\lim_{x\to+\infty}\left(\frac{x+a}{x-1}\right)^{x}=e^{3}\).

    \(1^\infty\): \(\ \dfrac{x+a}{x-1}-1=\dfrac{a+1}{x-1}\Rightarrow\displaystyle\lim_{x\to+\infty}\frac{(a+1)x}{x-1}=a+1\Rightarrow\) ⟪el límit és‖el límite es‖the limit is⟫ \(e^{a+1}\)

    \(e^{a+1}=e^{3}\Rightarrow a+1=3\Rightarrow a=2\)

  3. ⟪Troba \(a\) perquè el límit siga finit i calcula'l:‖Halla \(a\) para que el límite sea finito y calcúlalo:‖Find \(a\) so that the limit is finite, and compute it:⟫ \(\displaystyle\lim_{x\to2}\frac{x^2+ax-6}{x^2-4}\).

    ⟪El denominador s'anul·la en \(x=2\). El numerador també ho ha de fer:‖El denominador se anula en \(x=2\). El numerador también debe hacerlo:‖The denominator vanishes at \(x=2\). So must the numerator:⟫ \(4+2a-6=0\Rightarrow a=1\)

    \(\displaystyle\lim_{x\to2}\frac{x^2+x-6}{x^2-4}=\lim_{x\to2}\frac{\cancel{(x-2)}(x+3)}{\cancel{(x-2)}(x+2)}=\frac54\). ⟪Per a \(a\neq1\) ix \(\frac{k}{0}\): el límit no és finit.‖Para \(a\neq1\) sale \(\frac{k}{0}\): el límite no es finito.‖For \(a\neq1\) we get \(\frac{k}{0}\): the limit is not finite.⟫

  4. ⟪Dos paràmetres: troba \(a\) i \(b\) perquè‖Dos parámetros: halla \(a\) y \(b\) para que‖Two parameters: find \(a\) and \(b\) such that⟫ \(\displaystyle\lim_{x\to1}\frac{x^2+ax+b}{x-1}=3\).

    ⟪Ha de ser \(\frac00\): \(1+a+b=0\Rightarrow b=-1-a\). Aleshores \(x^2+ax-1-a=(x-1)(x+1+a)\) (Ruffini).‖Debe ser \(\frac00\): \(1+a+b=0\Rightarrow b=-1-a\). Entonces \(x^2+ax-1-a=(x-1)(x+1+a)\) (Ruffini).‖It must be \(\frac00\): \(1+a+b=0\Rightarrow b=-1-a\). Then \(x^2+ax-1-a=(x-1)(x+1+a)\) (Ruffini).⟫

    \(\displaystyle\lim_{x\to1}(x+1+a)=2+a=3\Rightarrow a=1,\ b=-2\)

  5. ⟪Amb infinitèsims: troba \(a\gt0\) perquè‖Con infinitésimos: halla \(a\gt0\) para que‖With infinitesimals: find \(a\gt0\) such that⟫ \(\displaystyle\lim_{x\to0}\frac{1-\cos(ax)}{x\sin x}=8\).

    \(\displaystyle\lim_{x\to0}\frac{\frac{a^2x^2}{2}}{x\cdot x}=\frac{a^2}{2}=8\Rightarrow a^2=16\Rightarrow a=4\)

  6. ⟪Discussió: calcula, segons els valors de \(a\),‖Discusión: calcula, según los valores de \(a\),‖Discussion: depending on \(a\), compute⟫ \(\displaystyle\lim_{x\to+\infty}\left(\sqrt{x^2+1}-ax\right)\).

    \(\sqrt{x^2+1}-ax\approx x-ax=(1-a)x\). ⟪Si \(a\lt1\), el límit és \(+\infty\); si \(a\gt1\), és \(-\infty\).‖Si \(a\lt1\), el límite es \(+\infty\); si \(a\gt1\), es \(-\infty\).‖If \(a\lt1\), the limit is \(+\infty\); if \(a\gt1\), it is \(-\infty\).⟫

    ⟪Si \(a=1\), és \(\infty-\infty\):‖Si \(a=1\), es \(\infty-\infty\):‖If \(a=1\), it is \(\infty-\infty\):⟫ \(\displaystyle\lim_{x\to+\infty}\frac{1}{\sqrt{x^2+1}+x}=0\).
