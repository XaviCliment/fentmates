⟪Funcions a trossos amb paràmetres: contínues i derivables‖Funciones a trozos con parámetros: continuas y derivables‖Piecewise functions with parameters: continuous and differentiable⟫

⟪Mètode‖Método‖Method⟫

⟪En cada punt de canvi \(a\) plantegem dues condicions:‖En cada punto de cambio \(a\) planteamos dos condiciones:‖At each break point \(a\) we set up two conditions:⟫

  1. ⟪Continuïtat: \(\displaystyle\lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a)\).‖Continuidad: \(\displaystyle\lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a)\).‖Continuity: \(\displaystyle\lim_{x\to a^-}f(x)=\lim_{x\to a^+}f(x)=f(a)\).⟫
  2. ⟪Derivabilitat: \(f'(a^-)=f'(a^+)\).‖Derivabilidad: \(f'(a^-)=f'(a^+)\).‖Differentiability: \(f'(a^-)=f'(a^+)\).⟫

⟪Obtenim un sistema d'equacions (no sempre lineal). Al final, comprovem que cada tros és derivable en el seu interval per als valors trobats. Si l'enunciat demana només continuïtat, després cal estudiar la derivabilitat amb els valors obtinguts.‖Obtenemos un sistema de ecuaciones (no siempre lineal). Al final, comprobamos que cada trozo es derivable en su intervalo para los valores encontrados. Si el enunciado pide solo continuidad, después hay que estudiar la derivabilidad con los valores obtenidos.‖We get a system of equations (not always linear). Finally, check that each piece is differentiable on its interval for the values found. If the question only asks for continuity, then study differentiability with the values obtained.⟫
