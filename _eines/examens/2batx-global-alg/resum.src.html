4[[Sistemes d'equacions lineals||Sistemas de ecuaciones lineales||Systems of linear equations]]

[[Tot sistema es pot escriure en forma matricial:||Todo sistema se puede escribir en forma matricial:||Every system can be written in matrix form:]]

  3.
