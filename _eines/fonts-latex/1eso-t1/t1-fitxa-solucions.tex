\seccio{4}{Problemes amb nombres naturals}

\ex{1} $612:36=\res{17\text{ €}}$ cada baló.

\ex{1} Treballa $31-6=25$ dies i fa $13\cdot12=156$ pastissos al dia: \ $156\cdot25=\res{3900\text{ pastissos}}$.

\ex{1} De cada caixa en sobreviuen $758-27=731$: \ $731\cdot45=\res{32\,895\text{ alevins}}$.

\ex{2} $(34+12)\cdot15=46\cdot15=690$ kg; \ $690\cdot2=\res{1380\text{ €}}$.

\ex{2} $43\cdot7\cdot147\cdot15=301\cdot147\cdot15=44\,247\cdot15=\res{663\,705\text{ €}}$.

\ex{2} Alumnes: $28+27+29+26=110$; persones: $118$. \ $118:55\to q=2,\ r=8$: calen \res{3\text{ autobusos}}.\\ $3\cdot330=990$ €; \ $990:110=\res{9\text{ €}}$ per alumne.

\ex{2} Trencades: $23\,400:3=7800$. \ Senceres: $23\,400-7800=15\,600$. \ $15\,600:12=\res{1300\text{ caixes}}$.

\ex{2} Preu d'un quilo: $9100:1300=7$ €. \ $1750\cdot7=\res{12\,250\text{ €}}$.

\ex{3} De cada 5 en pague 4: dels 20 n'he pagat $20:5\cdot4=16$. \ $64:16=\res{4\text{ €}}$ cada retolador.

\ex{3} Seients: $24\cdot18=432$; buits: $432-350=\res{82}$. \ Recaptat: $350\cdot7=\res{2450\text{ €}}$.\\ Ple: $432\cdot7=3024$ €; \ $3024-2450=\res{574\text{ €}}$ més.

\ex{3} Falten $1380-300=1080$ €. \ $1080:90=\res{12\text{ quotes}}$ (un any).
