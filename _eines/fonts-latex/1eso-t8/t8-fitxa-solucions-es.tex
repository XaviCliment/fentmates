  \task $\sqrt{16+16}=\sqrt{32}\approx\res{5,66\text{ cm}}$
\end{tasks}

\ex{1} La altura divide la base en dos mitades de 8\,cm: \ $h=\sqrt{10^2-8^2}=\sqrt{36}=\res{6\text{ cm}}$. \ $A=\frac{16\cdot6}{2}=\res{48\text{ cm}^2}$. \ $P=16+10+10=\res{36\text{ cm}}$

\ex{2} Las semidiagonales miden 9 y 12\,cm: \ $l=\sqrt{81+144}=\sqrt{225}=\res{15\text{ cm}}$. \ $P=4\cdot15=\res{60\text{ cm}}$. \ $A=\frac{18\cdot24}{2}=\res{216\text{ cm}^2}$

\ex{2} Triángulo de catetos $12-7=5$ y 12: \ $c=\sqrt{25+144}=\sqrt{169}=13$\,cm. \ $P=12+7+12+13=\res{44\text{ cm}}$. \ $A=\frac{(12+7)\cdot12}{2}=\res{114\text{ cm}^2}$

\ex{2} A cada lado sobran $(16-4):2=6$\,cm: \ $h=\sqrt{100-36}=\res{8\text{ cm}}$. \ $A=\frac{(16+4)\cdot8}{2}=\res{80\text{ cm}^2}$. \ $P=16+4+10+10=\res{40\text{ cm}}$

\ex{2} El radio es igual al lado (4\,cm): \ $a=\sqrt{4^2-2^2}=\sqrt{12}\approx\res{3,46\text{ cm}}$. \ $P=6\cdot4=24$\,cm; \ $A=\frac{24\cdot3,46}{2}=\res{41,52\text{ cm}^2}$

\ex{3} Lado: $18:3=6$\,cm. \ $h=\sqrt{6^2-3^2}=\sqrt{27}\approx\res{5,20\text{ cm}}$. \ $A=\frac{6\cdot5,2}{2}=\res{15,6\text{ cm}^2}$

\ex{3} La diagonal del cuadrado es un diámetro (8\,cm): \ $l^2+l^2=64\Rightarrow l^2=32$, que es el área del cuadrado. \ $A=3,14\cdot4^2-32=50,24-32=\res{18,24\text{ cm}^2}$

\ex{3} Cada lado del tejado: $\sqrt{4^2+3^2}=\sqrt{25}=5$\,m. \ $P=8+5+5+5+5=\res{28\text{ m}}$. \ $A=8\cdot5+\frac{8\cdot3}{2}=\res{52\text{ m}^2}$
