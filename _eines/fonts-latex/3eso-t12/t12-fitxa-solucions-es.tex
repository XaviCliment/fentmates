\seccio{2}{Probabilidad de un suceso. Propiedades}

\ex{1} $h$: \ $\res{0{,}14}$, \ $\res{0{,}18}$, \ $\res{0{,}16}$, \ $\res{0{,}2}$, \ $\res{0{,}12}$, \ $\res{0{,}2}$ \ (suman 1). \quad $h(\text{par})=\frac{9+10+10}{50}=\res{0{,}58}$.

\ex{1} Una probabilidad siempre está entre 0 y 1. Pueden serlo: \rest{$0{,}7$, \ $0$, \ $100\,\%$ y $\frac{99}{100}$}. No pueden serlo: $1{,}2$, $-0{,}1$, $\frac32$ y $\frac54$.

\ex{1} $P(\text{verde})=1-(0{,}5+0{,}3)=\res{0{,}2}$. \ $P(\text{rojo o verde})=0{,}5+0{,}2=\res{0{,}7}$.

\ex{2} $P(\text{amarillo})=1-(0{,}35+0{,}25+0{,}1)=\res{0{,}3}$. \ $P(\text{no rojo})=P(\text{azul})+P(\text{verde})+P(\text{amarillo})=0{,}25+0{,}1+0{,}3=\res{0{,}65}$. \ $P(\text{azul o amarillo})=0{,}25+0{,}3=\res{0{,}55}$.

\ex{2} Si $P(1)=\dots=P(5)=x$: \ $5x+0{,}5=1\Rightarrow x=\res{0{,}1}$. \ $P(\text{par})=0{,}1+0{,}1+0{,}5=\res{0{,}7}$. \ $P(\text{menos de 3})=0{,}1+0{,}1=\res{0{,}2}$.

\ex{3} Las seis probabilidades suman 1: $p+2p+\dots+6p=21p=1\Rightarrow p=\res{\frac1{21}}$. \ $P(6)=\frac6{21}=\res{\frac27}$. \ $P(\text{par})=\frac{2+4+6}{21}=\frac{12}{21}=\res{\frac47}$.

\ex{3} Si $P(\text{azul})=x$: \ $2x+x+0{,}4=1\Rightarrow x=0{,}2$. \ $P(\text{roja})=\res{0{,}4}$, \ $P(\text{azul})=\res{0{,}2}$. \ Con 20 bolas: \res{8 rojas, 4 azules y 8 verdes}.
