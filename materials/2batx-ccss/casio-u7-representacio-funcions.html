1Domini: denominadors i arrels quadrades

  1. Funcions racionals: les arrels del denominador (Ecuación › Polinómica) no són del domini.
  2. Arrels quadrades: el radicand ha de ser $\ge0$. Si és un polinomi de grau 2, 3 o 4, resol-ho amb ⌂ › Inecuación i el signe ≥0.
Exemple

Domini de $f(x)=\sqrt{x^2-4}$

⌂ Inecuación OK ax²+bx+c ax²+bx+c≥0 1 EXE 0 EXE ⇧ − 4 EXE EXE
Pantallax ≤ −2, 2 ≤ x

💡 Consell: Domini: $(-\infty,-2]\cup[2,+\infty)$. Si el radicand és un quocient, estudia el signe del numerador i del denominador per separat.

2Talls amb els eixos

  1. Eix Y: calcula f(0) (si 0 és del domini).
  2. Eix X: resol $f(x)=0$. Per a una fracció, només cal el numerador. Si és un polinomi, usa Polinómica; si no, Resolver.
  3. Amb arrels quadrades o logaritmes, comprova que la solució és del domini: pot ser una solució falsa.
Exemple

$f(x)=\dfrac{x^3-4x}{x^2+1}$

Polinómica ax³+bx²+cx+d 1 EXE 0 EXE ⇧ − 4 EXE 0 EXE EXE
Pantallax₁ = 2·x₂ = −2·x₃ = 0 → (−2, 0), (0, 0), (2, 0)

3Simetries

Si $f(-x)=f(x)$ la funció és parell (simètrica respecte de l'eix Y); si $f(-x)=-f(x)$, és senar (simètrica respecte de l'origen).

  1. A la Tabla, defineix f(x) amb la funció i g(x) = f(−x): f(x) › f(x) ⇧ − x ).
  2. Genera la taula. Si les columnes són iguals → parell. Si són oposades → senar.
Exemple

$f(x)=\dfrac{x^3-4x}{x^2+1}$

Definir g(x) f(x) f(x) ⇧ − x ) EXE · Rango tabla 1 EXE 4 EXE 1 EXE Ejecutar
Pantallaf(1) = −1,5 | g(1) = 1,5·f(3) = 1,5 | g(3) = −1,5 → senar

💡 Consell: La taula només ho suggereix; a l'examen has de fer el càlcul de $f(-x)$ algebraicament.

4Taula de valors per dibuixar

  1. ⋯ › Tipo de tabla › f(x): així caben fins a 45 files.
  2. ⋯ › Rango tabla: tria l'interval que vols dibuixar i un pas de 0,5 o 1.
  3. Afig a la columna x els punts importants (extrems, prop de les asímptotes).
Exemple

$f(x)=\dfrac{x^2}{x-1}$ entre $-3$ i $5$

Rango tabla ⇧ − 3 EXE 5 EXE 1 EXE Ejecutar
Pantalla−3 → −2,25·−1 → −0,5·0 → 0·1 → ERROR·2 → 4·3 → 4,5·5 → 6,25

💡 Consell: L'ERROR en $x=1$ marca l'asímptota vertical. Per a les asímptotes horitzontals i obliqües, mira la guia de la unitat 4.

5Monotonia i extrems de l'exemple

  1. Deriva a mà: $f'(x)=\dfrac{x^2-2x}{(x-1)^2}$. El denominador sempre és positiu, així que el signe depèn de $x^2-2x$.
  2. Resol $x^2-2x>0$ amb Inecuación (on creix) i $x^2-2x=0$ amb Polinómica (punts crítics).
  3. Calcula f en cada punt crític per tindre les coordenades.
Exemple

$f(x)=\dfrac{x^2}{x-1}$

Inecuación ax²+bx+c ax²+bx+c>0 1 EXE ⇧ − 2 EXE 0 EXE EXE
Pantallax < 0, 2 < x → màxim (0, 0)·mínim (2, 4)

💡 Consell: Recorda excloure $x=1$, que no és del domini: decreix en $(0,1)\cup(1,2)$.

6Funcions amb $e^x$ i $\ln x$

  1. $e$ és ⇧ 8 i $\ln$ és ⇧ log▭▭.
  2. Per als talls i extrems que no ixen amb polinomis, usa Resolver i prova diversos valors inicials.
  3. Si la taula dona ERROR per a algun x, eixe valor no és del domini (per exemple, $\ln x$ amb $x\le0$).
Exemple

On talla l'eix X $f(x)=x\ln x-1$?

⌂ Ecuación Resolver x ⇧ log▭▭ x ) − 1 CATALOG Ecuación = 0 EXE EXE 2 EXE
Pantallax = 1,763222834

💡 Consell: Resolver troba una sola solució cada vegada (la més pròxima al valor inicial). Fes primer una taula per saber quantes n'hi ha i on són.
