  • Les guies suposen la configuració de fàbrica (entrada i eixida «E Mat/S Mat»). Si la teua calculadora fa coses estranyes: ☰ › Reiniciar › Config y datos.

1Entrar a l'aplicació i guardar una matriu

La calculadora treballa amb quatre matrius guardades: MatA, MatB, MatC i MatD.

  1. Prem ⌂, tria l'aplicació Matriz i prem OK.
  2. Prem ⋯ per veure la llista de matrius. Tria MatA: i prem OK (si ja n'hi havia una, tria Definir nuevo/a).
  3. Tria Filas i Columnas i després Confirmar.
  4. Escriu els elements fila a fila, prem EXE després de cada número. Els negatius s'escriuen amb ⇧ −.
  5. Prem AC per tornar a la pantalla de càlcul.
Exemple

Guarda $A=\begin{pmatrix}2&1\\3&2\end{pmatrix}$ i $B=\begin{pmatrix}1&-1\\0&2\end{pmatrix}$

⋯ MatA: OK Confirmar 2 EXE 1 EXE 3 EXE 2 EXE AC
⋯ MatB: OK Confirmar 1 EXE ⇧ − 1 EXE 0 EXE 2 EXE AC
PantallaMatA: 2×2·MatB: 2×2

💡 Consell: Les matrius es queden guardades encara que apagues la calculadora. Si et cal canviar-ne un element, tria la matriu a la llista i Editar.

2Escriure una matriu en una operació

  1. A la pantalla de càlcul, prem CATALOG › Matriz › MatA (o la que vulgues).
  2. Les operacions + − × es fan amb les tecles normals.
Exemple

$A+B$, $A\cdot B$ i $3A$

CATALOG Matriz MatA + CATALOG Matriz MatB EXE
CATALOG Matriz MatA × CATALOG Matriz MatB EXE
3 × CATALOG Matriz MatA EXE
PantallaA+B = 3034·A·B = 2031·3A = 6396

💡 Consell: Si les dimensions no permeten l'operació, ix «ERROR Dimensión». Recorda: $A_{m\times n}\cdot B_{n\times p}$ (les columnes d'A han de coincidir amb les files de B).

3Potències, inversa, transposada i identitat

Totes estan dins de CATALOG › Matriz › Cálculos matriz.

  1. Quadrat i cub: escriu MatA i després Cálculos matriz › Mat al cuadrado o Matriz cúbica.
  2. Inversa: escriu MatA i després Cálculos matriz › Matriz inversa (posa el ⁻¹).
  3. Transposada: Cálculos matriz › Transpuesta i després MatA.
  4. Identitat: Cálculos matriz › Identidad i la dimensió (per exemple 2).
Exemple

$A^2$, $A^{-1}$ i $A^t$

CATALOG Matriz MatA CATALOG Matriz Cálculos matriz Mat al cuadrado EXE
CATALOG Matriz MatA CATALOG Matriz Cálculos matriz Matriz inversa EXE
CATALOG Matriz Cálculos matriz Transpuesta CATALOG Matriz MatA ) EXE
PantallaA² = 74127·A⁻¹ = 2−1−32·Aᵗ = 2312

💡 Consell: Si la matriu no té inversa (determinant 0), la calculadora dona error. Els elements fraccionaris de la inversa es veuen com a fraccions.

5Rang d'una matriu

La calculadora no té una funció «rang», però el pots llegir a la forma esglaonada: el rang és el nombre de files que no són tot zeros.

  1. Guarda la matriu (per exemple a MatC).
  2. CATALOG › Matriz › Cálculos matriz › F esc reducida i després MatC. Prem EXE.
  3. Compta les files que no són totes zero.
Exemple

Rang de $C=\begin{pmatrix}1&2&3\\2&4&6\\1&0&1\end{pmatrix}$

CATALOG Matriz Cálculos matriz F esc reducida CATALOG Matriz MatC ) EXE
Pantalla101011000 → rang 2

💡 Consell: Form escalonada fa el mateix que el mètode de Gauss, i F esc reducida deixa uns i zeros (Gauss-Jordan). Totes dues serveixen per al rang.

6Equacions matricials

Primer aïlla la X a mà (amb l'ordre correcte!) i després calcula amb la calculadora.

  1. $AX=B\ \Rightarrow\ X=A^{-1}B$ (la inversa multiplica per l'esquerra).
  2. $XA=B\ \Rightarrow\ X=BA^{-1}$ (la inversa multiplica per la dreta).
  3. Escriu l'expressió amb les matrius guardades i prem EXE.
Exemple

Resol $AX=B$ i $XA=B$

CATALOG Matriz MatA Matriz inversa × CATALOG Matriz MatB EXE
CATALOG Matriz MatB × CATALOG Matriz MatA Matriz inversa EXE
PantallaAX=B: X = 2−4−37·XA=B: X = 5−3−64

💡 Consell: Com que el producte de matrius no és commutatiu, $A^{-1}B\neq BA^{-1}$: fixa't que els dos resultats són diferents.
