Distribucions bidimensionalsDistribuciones bidimensionalesBivariate distributions

Variables estadístiques bidimensionalsVariables estadísticas bidimensionalesTwo-variable (bivariate) data

A la unitat anterior estudiàvem una sola característica de cada individu. Moltes vegades, però, ens interessa saber si dues característiques estan relacionades: si qui estudia més trau més bona nota, si les persones més altes pesen més, si quan fa més calor es venen més gelats…En la unidad anterior estudiábamos una sola característica de cada individuo. Muchas veces, sin embargo, nos interesa saber si dos características están relacionadas: si quien estudia más saca mejor nota, si las personas más altas pesan más, si cuando hace más calor se venden más helados…In the previous unit we studied a single feature of each individual. Often, though, we want to know whether two features are related: whether people who study more get better marks, whether taller people weigh more, whether more ice creams are sold when it's hotter…

  • Una variable estadística bidimensional \((X,\,Y)\) estudia dues variables \(X\) i \(Y\) sobre els mateixos individus.Una variable estadística bidimensional \((X,\,Y)\) estudia dos variables \(X\) e \(Y\) sobre los mismos individuos.A bivariate statistical variable \((X,\,Y)\) studies two variables \(X\) and \(Y\) on the same individuals.
  • Cada individu ens dona una parella de valors \((x_i,\,y_i)\): el primer és el valor de \(X\) i el segon, el de \(Y\).Cada individuo nos da una pareja de valores \((x_i,\,y_i)\): el primero es el valor de \(X\) y el segundo, el de \(Y\).Each individual gives us a pair of values \((x_i,\,y_i)\): the first is the value of \(X\) and the second the value of \(Y\).
  • El conjunt de totes les parelles és una distribució bidimensional. El nombre de parelles és \(N\).El conjunto de todas las parejas es una distribución bidimensional. El número de parejas es \(N\).The set of all the pairs is a bivariate distribution. The number of pairs is \(N\).

  • Sentit. La correlació és positiva (o directa) si, quan \(X\) creix, \(Y\) també tendeix a créixer: el núvol «puja».
